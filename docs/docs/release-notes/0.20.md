# Version 0.20

Sheriff 0.20.0 adds ESLint 10 support, richer dependency-rule callbacks, and access
to original import specifiers through `getProjectData`.

## ESLint 10 support

`@softarc/eslint-plugin-sheriff` now supports ESLint 10 alongside ESLint 8 and 9.
ESLint 10 requires flat configuration; existing legacy configurations remain
supported when used with ESLint 8 or 9.

Compatibility tests cover TypeScript 4.8, 4.9, 5.0–5.9, and 6.0 across ESLint 8.57.1
and 9 with legacy and flat configurations, plus ESLint 10 with flat configuration.
The Angular fixtures cover Angular 15, 18, and 22.2, including the older ESLint 8.36
rule context API.

See [PR #252](https://github.com/softarc-consulting/sheriff/pull/252).

## Dependency rules can inspect all module tags

Dependency-rule callbacks now receive `fromTags` and `toTags`, containing all tags
of the source and destination modules. The existing `from` and `to` fields still
identify the individual tags being checked.

This allows a catch-all rule to consider a module's domain and type together:

```typescript
depRules: {
  '*': ({ fromTags, toTags }) => {
    const fromDomain = fromTags.find((tag) => tag.startsWith('domain:'));
    const toDomain = toTags.find((tag) => tag.startsWith('domain:'));

    return toTags.includes('type:api') ||
      (fromDomain !== undefined && fromDomain === toDomain);
  },
},
```

In this example, a dependency is allowed when the destination is an API module or
both modules belong to the same domain.

See [PR #246](https://github.com/softarc-consulting/sheriff/pull/246) and its
[follow-up #256](https://github.com/softarc-consulting/sheriff/pull/256).

## Original import specifiers in project data

Pass `includeRawImports: true` to include the original import strings in the
output of `getProjectData`:

```typescript
import { getProjectData } from '@softarc/sheriff-core';

const data = getProjectData('src/main.ts', process.cwd(), {
  includeRawImports: true,
});
```

Each entry gets a `rawImports` object. Its keys are resolved imported file paths;
each value is an array of the specifiers used to import that file. For example,
both `@lib/kit/sub` and `./sub` can be preserved when they resolve to the same file.
This option is opt-in; the default output is unchanged.

See [PR #267](https://github.com/softarc-consulting/sheriff/pull/267).

## Upgrading

Upgrade both packages together:

```sh
npm install --save-dev @softarc/sheriff-core@0.20.0 @softarc/eslint-plugin-sheriff@0.20.0
```

Existing dependency-rule callbacks can continue using `from` and `to`. Consumers
that construct the internal `DependencyCheckContext` type directly must also
provide the new `fromTags` and `toTags` arrays.

The repository's move to pnpm and its TypeScript 6 development toolchain do not
require consumers to change package manager or upgrade to TypeScript 6.
`ignoreFileExtensions` was already available in 0.19.6 and is not a new feature
of this release.
